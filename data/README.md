# GSE17154 Data Directory

This directory stores the primary data for the gastric cancer transcriptomics study:
- `annotation/`: Contains the probe-to-gene mapping table derived from GPL6699.
- `metadata/`: Contains curated clinical attributes for all 49 biological samples.
- `processed_matrix/`: Contains the normalized expression matrix.

To download raw archive files, refer to NCBI GEO accession GSE17154.
